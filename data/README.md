# 📁 测试数据目录

此目录用于存放 RAG 系统的测试文档。

## 📄 支持的文件类型

| 类型 | 扩展名 | 说明 |
|------|--------|------|
| PDF | `.pdf` | 本项目主要支持的文档格式 |

## 💡 建议放置的文档

- 技术文档（如 API 文档、使用手册）
- 学术论文
- 产品说明书
- 任何你想要进行问答的 PDF 文档

## ⚠️ 注意事项

1. **文件大小**：建议单个文件不超过 50MB
2. **文档质量**：文字清晰的 PDF 效果更好，扫描件可能识别率较低
3. **隐私安全**：不要上传包含敏感信息的文档
4. **Git 忽略**：大型 PDF 文件建议添加到 `.gitignore`

## 📥 示例

你可以从以下来源获取测试文档：

- [arXiv](https://arxiv.org/) - 学术论文
- [LangChain 文档](https://python.langchain.com/) - 技术文档
- 任何你感兴趣的 PDF 文档

## 🔧 使用方法

将 PDF 文件放入此目录后，运行示例代码：

```bash
python 01_loaders/pdf_loader.py
```
